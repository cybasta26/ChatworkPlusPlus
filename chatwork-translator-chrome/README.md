## 统一跳转与相关信息（当前规则）

- 顶部显示 `TO: 5   RE: 10   SEND: 5`，只显示计数，无需选择分类。上下箭头按消息顺序循环跳转所有匹配消息；一条消息命中多个分类仍只经过一次，分类数量各自保留。

# Chatwork 中文翻译 · Chrome Google 版 v1.5.0

与 Edge v1.5.0 同步界面和文字处理规则，翻译服务仍为 Google，无需下载 Edge 模型。

## 安装与更新

1. Chrome 打开 chrome://extensions，开启「开发者模式」。
2. 「加载已解压的扩展程序」，选择 F:\Projects\DCG\DCG_Doc\ChatworkPlusPlus\chatwork-translator-chrome。
3. 已安装的用户点击该扩展「重新加载」，再刷新 Chatwork。
4. 打开插件面板，开启自动翻译。分享 ZIP 时先解压到固定文件夹，再加载。

## 同步功能

- 原文下显示译文，新消息、历史加载、切换聊天室、正文编辑自动处理；仅处理进入视野的消息。
- 所有实际换行和空行原样保留，逐行完整翻译。数字、时间、英文不从同一行里拆开。自动折行不是原文换行；跨行句子的上下文会减少。
- 可识别人名、TO:/RE:、链接、重复分隔线与装饰符号保留。模型改写保护标记时尝试恢复，失败后自动对该行分段回退。
- 明确为中文的整条聊天消息跳过，不显示重复译文框。保守本地判断，不确定的短句仍可能翻译。
- 独立手动翻译拨动开关，关闭隐藏输入输出；默认中文→日语，可选择中文、日语、英语、韩语。支持 Ctrl+Enter 和复制译文。
- 手动翻译独立于聊天开关，中文输入照常可翻译到其他语言。输入与译文不持久保存，关闭面板清空；开关、语言选择会保存。
- 紧凑面板同时显示输入和输出，没有整页滚动条；长文字在文本框内滚动。

## 网络与数据

开启自动翻译或点击手动翻译会将相应正文发送给 Google，包括未识别的人名及正文引用。附件不下载、不翻译。插件不发送 Chatwork 消息，不改输入框。

使用 translate.googleapis.com 的免密钥接口，需要网络能连接 Google，可能限流或变更，没有可用性保证。不开通付费 API。翻译结果仅在后台内存缓存最多 300 个请求，缓存按源语言和目标语言区分。

聊天翻译源语言自动检测，目标为简体中文；手动翻译使用所选语言。暂停后不启动新的请求，已发出的网络请求可能完成。
