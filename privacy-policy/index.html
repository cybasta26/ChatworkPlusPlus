English

This policy describes how the Chatwork++ browser extension processes information. It covers the Microsoft Edge on-device translation edition and the Google Chrome Google translation edition. The contact for the extension is its maintainer at morningstar.b@gmail.com.

The editions handle translation differently. Edge translates text on your device using the browser’s translation model. Chrome sends text being translated to Google’s translation service. Local archiving stores records on your device, not on a publisher-operated archive server.

1. Information the extension processes

  • Chat messages accessible in supported Chatwork pages, including message text, timestamps, message and room identifiers, room names, sender and recipient information, mentions, reply relationships, and member names and avatars.
  • Attachment names, identifiers, links and, when saved to an archive or exported, attachment contents.
  • Text you enter for manual translation, message links you enter for archive searches, search terms and filter selections.
  • Extension preferences, language choices, local Thread read markers, archive indexes, archive progress, and the selected archive directory handle. Directory ownership markers identify the extension installation to help prevent conflicting writes.
  • Local diagnostic information such as permission state, failure stage, error details, extension version, browser user-agent information and time of a check.

2. Purposes and processing

This information is used to provide translation, message search and navigation, related-message Threads, recent relevant topics, local archives, attachment handling, exports, and troubleshooting. The extension uses your existing Chatwork session to access content you are permitted to view. It does not ask you to supply your Chatwork password to the publisher or bypass Chatwork access restrictions.

3. Translation and external services

Edge edition: translation text is processed through the browser’s on-device translation API and is not sent by this edition to a cloud translation service. Language-model downloads may require a network connection. Normal Chatwork requests, attachment retrieval and browser services still use the network.

Chrome edition: text submitted for automatic or manual translation, including chat messages or room names, is sent over HTTPS to translate.googleapis.com. The content can include personal information present in that text. Translation requests omit browser credentials; Google still receives the request content and connection information such as your IP address. Google’s processing is governed by its Privacy Policy. Disable automatic translation and avoid manual translation if you do not want text sent to that service.

Chatwork content and attachments are requested from Chatwork and its delivery services using the existing signed-in session where required. User-initiated attachment or clipboard-image actions may send the selected content to Chatwork. Chatwork and browser-provider services are governed by their own policies.

4. Storage, retention and deletion

Preferences, indexes, archived messages and operational data are stored in browser extension storage or its local database. Archive backups and saved attachments are written to the directory you choose. Exports and saved copies remain in locations you select. This extension does not provide publisher-operated cloud synchronization for archives.

Local data is retained until you clear it or the browser removes it. In chat-history management, date-based cleanup removes messages strictly before the selected date; it currently retains attachment files. Deleting an empty archive entry removes that chat’s archive directory, including its archived attachments. Copies exported or saved elsewhere are not removed. Disabling automatic archiving stops future automatic archiving but does not delete existing records. Content still accessible in Chatwork may be archived again when archiving runs.

Uninstalling or clearing extension storage does not delete archive folders and exports saved outside the browser. Delete those files separately if you no longer want them. Local archives are not encrypted by the extension; protect the device, account and folder, especially on shared computers. A folder synchronized by another application may be copied to that application’s cloud service.

5. Permissions and user control

  • Supported-site access: reads and enhances Chatwork pages for the features described above.
  • storage / unlimitedStorage: saves settings and local archive data that may grow beyond ordinary storage quotas.
  • alarms: periodically checks and continues enabled archive tasks when the background worker is inactive.
  • Folder access: reads and writes the archive directory you authorize. Permission can be withdrawn through browser controls.
  • Clipboard and downloads: used for actions such as copying translations or Thread images, pasting an image and saving exports when initiated by you.

You can disable automatic translation, room-name translation, recent-topic hints and automatic archiving in the extension controls, and remove the extension through the browser.

6. Sharing, analytics and support

The extension does not include advertising analytics or tracking code, does not sell personal information, and does not automatically send chat archives or diagnostic reports to the maintainer. External processing described in section 3 still applies. If you email the maintainer, the message, email address and any attachments you choose to provide are processed to respond to your request. Avoid including confidential chats, credentials or unnecessary personal information in support reports.

7. This page and policy changes

This page contains no analytics scripts, external fonts or embedded trackers. When hosted on GitHub Pages, GitHub may process visit and connection information under the GitHub Privacy Statement. This policy may be updated when extension behavior changes; the date above identifies the latest revision.

简体中文

本政策说明 Chatwork++ 浏览器扩展如何处理信息，适用于 Edge 本地翻译版和 Chrome Google 翻译版。维护者联系邮箱：morningstar.b@gmail.com。

两个版本的翻译方式不同：Edge 使用浏览器设备端模型处理翻译；Chrome 会把需要翻译的文本发送至 Google 翻译服务。本地归档保存在用户设备上，不上传到发布者运营的归档服务器。

1. 处理的信息及用途

扩展处理可访问的 Chatwork 消息正文、时间、消息及聊天室编号、群名、发信人和收信人、提及及回复关系、成员名称和头像；还可能处理附件名称、编号、链接和保存的附件内容。手动翻译文本、消息查询链接、搜索条件、语言及功能设置、Thread 阅读标记、归档索引和进度也用于对应功能。

目录句柄和安装实例的目录所有权标记用于保存归档、防止冲突写入。权限状态、错误阶段及详情、插件版本、浏览器信息和检查时间等诊断数据保存在本地。上述信息用于翻译、搜索、导航、相关话题、归档、附件处理、导出及排错。扩展使用现有登录会话，不要求向发布者提供 Chatwork 密码，也不绕过访问限制。

2. 网络传输及第三方服务

Edge 版：通过浏览器设备端翻译 API 处理文本，不向云端翻译服务发送翻译文本。语言模型下载可能联网；Chatwork 页面、附件请求和浏览器服务仍会使用网络。

Chrome 版：自动或手动翻译的文本，包括消息及群名，通过 HTTPS 发送到 translate.googleapis.com，可能包含原文中的个人信息。翻译请求不附带浏览器凭据，但 Google 会收到请求内容和 IP 地址等连接信息，其处理遵循 Google 隐私政策。若不希望发送文本，请关闭自动翻译且不要使用手动翻译。

消息和附件通过现有会话从 Chatwork 及其内容服务获取。用户主动执行的附件或剪贴板图片操作可能将所选内容发送至 Chatwork。相关服务及浏览器服务适用各自的隐私政策。

3. 保存期限和删除

设置、索引、消息和运行数据保存在扩展的浏览器存储及本地数据库中；归档备份和附件保存在用户选择的目录，导出文件保存在指定位置。扩展不提供由发布者运营的归档云同步。数据保留至用户清理或浏览器移除。

按日期清理仅删除指定日期之前的消息，目前保留附件文件。删除空归档条目会删除该聊天的归档目录及附件，不影响另存到其他位置的副本。关闭自动归档不会删除既有数据；后续归档运行时，Chatwork 中仍可访问的内容可能再次被归档。

卸载扩展或清除浏览器扩展存储不会删除浏览器外的归档目录和导出文件，需要自行删除。扩展未对本地归档加密，请保护设备、系统账号和文件夹。如果目录由其他软件同步，文件可能被该软件同步到云端。

4. 权限与控制

受支持站点访问用于读取和增强 Chatwork 页面；storage 和 unlimitedStorage 用于设置及长期积累的本地归档；alarms 用于定期检查和继续已启用的归档任务；目录权限用于读写用户授权的文件夹；剪贴板和下载用于用户发起的复制、粘贴图片和导出操作。可在扩展设置中关闭自动翻译、群名翻译、相关话题提示及自动归档，并通过浏览器管理权限或卸载扩展。

5. 共享、诊断与联系

扩展不包含广告分析或跟踪代码，不出售个人信息，也不会自动向维护者发送聊天归档或诊断报告；上述第三方服务处理仍然适用。主动发送的支持邮件、邮箱地址及附件用于回复和处理问题，请勿提供密码、机密聊天或不必要的个人信息。

本网页不包含统计脚本、外部字体或跟踪嵌入。若托管于 GitHub Pages，GitHub 可能依据其 隐私声明处理访问及连接信息。功能发生变化时，本政策可能更新，顶部日期表示最新修订时间。
